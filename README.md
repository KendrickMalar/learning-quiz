# learning-quiz

読んだ本や学びたい分野を、クイズで繰り返し解いて定着させるためのリポジトリです。

1冊の本や1つの分野を「セッション」として持ちます。読み進めるたびに問題を足して育て、すきま時間に一覧から選んで解きます。

- 作る・足す: Claude Code で「この本の問題作って」「〇〇の続き読んだ」
- 解く: Claude Code で「クイズして」（最後に触った順にセッションが並びます）
- 成績: GitHub Pages のトップページ

間違えた問題と、復習の時期が来た問題（正解が続くほど 1日→2日→4日… と間隔が延びる）を優先して出します。それを出し切ったら、時期前の問題も続けて出します。
